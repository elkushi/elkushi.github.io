دراسة حالة · منتج ذكاء اصطناعي

مولّد الفيديو والصور بالذكاء الاصطناعي

تطبيقي الخاص. أعطه هوية علامة وموضوعًا، فيخطّط ويكتب ويعلّق صوتيًا وينفّذ ويراجع فيديوهات قصيرة ومنشورات مصوّرة لـ LinkedIn و Reels و TikTok والويب.

  • الدور: المطوّر الوحيد
  • التقنيات: Claude Code و Python و FastAPI و React + TypeScript و Remotion و Docker
  • الكود: github.com/elkushi/ai-video-image-generator

الفكرة

أردت فيديوهات قصيرة تلتزم بهوية العلامة، لا تكلّف شيئًا لكل فيديو، وتُنتَج حتى حين تتعطّل خدمة ذكاء اصطناعي على الإنترنت أو تنفد حصّتها.

كيف يعمل

Claude يتخذ القرارات. وسكربتات Python تنفّذ العمل.

  1. وكيل استراتيجية يختار الجمهور والزاوية والخطّاف والدعوة إلى الفعل.
  2. وكيل كتابة سيناريو يكتب الاستوري بورد: التعليق الصوتي والنص على الشاشة وأنواع المشاهد.
  3. يُفحص الاستوري بورد مقابل JSON schema قبل تشغيل أي خطوة بطيئة.
  4. أدوات Python تنتج الصوت، وتجلب أو تولّد العناصر البصرية، وتختار الموسيقى.
  5. Remotion، وهو إطار فيديو على React، ينفّذ كل نسب العرض.
  6. خطوة المراجعة تفحص المدة ومستويات الصوت والإطارات السوداء، وتفرّغ الصوت بـ Whisper لمقارنته بالنص.
  7. وكيل مراجِع يقرأ تقرير الجودة ويعيد SHIP أو قائمة إصلاحات. جولتا إصلاح كحد أقصى.

المسار نفسه ينتج منشورات مصوّرة وكاروسيل. الفيديوهات تخرج بالإنجليزية أو العربية أو الروسية. والنصوص العربية تسير من اليمين إلى اليسار.

ثلاثة خيارات، تختار واحدًا

للمنشور المصوّر، ينتج التطبيق ثلاث زوايا مختلفة، لكل منها تصميمها ونصّها لـ LinkedIn و Instagram. تختار واحدًا، وتعدّل النص إن أردت، فيسلّمك الشرائح وملف كاروسيل PDF ونصّ المنشور.

ناتج حقيقي · 24 ثانية · 9:16

فيديو مكتمل، من صنع التطبيق

موجز واحد لعلامة دفاتر متخيّلة. الوكلاء كتبوا النص، والصوت صوت عصبي مجاني، و Remotion نفّذ، وخطوة المراجعة أجازته. بلا أي تعديل بشري.

التشغيل نفسه سلّم أيضًا نسخة 4:5 لخلاصتَي LinkedIn و Instagram.

القيود التي وضعتها

  • بلا واجهات مدفوعة. لكل خطوة ذكاء اصطناعي خيار مجاني على الإنترنت وبديل محلي: أصوات Piper، و Stable Diffusion محليًا، وشخصية مرسومة بدل المتحدّث.
  • يعمل على حاسوب محمول عادي. على حاسوبي، تُنفَّذ معاينة من 26 ثانية في نحو 50 ثانية. وصورة ذكاء اصطناعي محلية تستغرق نحو 9 دقائق على المعالج، لذا تأتي الخيارات عبر الإنترنت أولًا.
  • لا شيء يُسلَّم دون فحص. فحص المخطّط وخطوة المراجعة يستطيعان إيقاف أي تشغيل.

تطبيق الويب

خلفية على FastAPI تشغّل Claude Code في الوضع الصامت، وواجهة على React + TypeScript تبثّ كل وكيل وأداة مباشرة أثناء العمل. يعمل داخل Docker، مع اختبارات وتكامل مستمر على GitHub Actions.

الأمان

التطبيق يشغّل وكيل ذكاء اصطناعي على خادم، لذا فهو مغلق افتراضيًا:

  • الوكيل لا يستطيع استخدام غير قائمة أدوات مسموح بها: سكربتات المشروع نفسه و ffmpeg وبضعة أوامر للقراءة فقط. وبقية التكاملات محجوبة.
  • كل ملف مرفوع يجب أن يكون داخل مجلد الرفع. والاختبارات تجرّب /etc/passwd و ../../etc/passwd و .env.
  • الوضع العام يعمل خلف HTTPS وتسجيل دخول لكل شخص بكلمات مرور مخزّنة بالتجزئة، مع ترويسات أمان وحدّ لحجم الرفع.
  • الحاوية تعمل بمستخدمها الخاص، لا بصلاحيات الجذر. والمفاتيح في .env خارج git.

الخطوة التالية

لم أقس بعد تكلفة Claude لكل فيديو. تطبيق الويب يسجّل بالفعل عدد التوكنات لكل مهمة، فالخطوة التالية تحويل ذلك إلى تكلفة لكل فيديو.
