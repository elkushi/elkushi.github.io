الفكرة

أردت فيديوهات قصيرة تلتزم بهوية العلامة، ولا تكلّف شيئًا للفيديو الواحد، وتُنتَج حتى عندما تتعطل خدمة ذكاء اصطناعي عبر الإنترنت أو تنفد حصتها.

كيف يعمل

Claude يتخذ القرارات، وسكربتات Python تنفّذ العمل.

  1. وكيل استراتيجي يحدّد الجمهور والزاوية والمدخل الجاذب والدعوة إلى الإجراء.
  2. وكيل كاتب يكتب لوحة القصة (Storyboard): التعليق الصوتي، والنص على الشاشة، وأنواع المشاهد.
  3. تُفحص لوحة القصة وفق JSON Schema قبل تشغيل أي خطوة بطيئة.
  4. أدوات Python تولّد الصوت، وتجلب الصور والمقاطع أو تولّدها، وتختار الموسيقى.
  5. Remotion، وهو إطار لإنتاج الفيديو بـ React، يُخرج الفيديو بكل المقاسات.
  6. مراقبة الجودة تفحص المدة ومستوى الصوت واللقطات السوداء، وتحوّل الصوت إلى نص بـ Whisper لمطابقته مع السيناريو.
  7. وكيل مراجعة يقرأ تقرير الجودة، ويعيد إما «اعتماد» أو قائمة إصلاحات. جولتا إصلاح كحدّ أقصى، ثم يتوقف التشغيل.

المسار نفسه يُنتج المنشورات المصوّرة والكاروسيل. وتخرج الفيديوهات بالإنجليزية أو العربية أو الروسية، والنصوص العربية على الشاشة تُكتب من اليمين إلى اليسار.

ثلاثة خيارات، وتختار واحدًا

للمنشور المصوّر، يقدّم التطبيق ثلاث زوايا مختلفة، لكل منها تصميمها ونصّها الخاص لـ LinkedIn وInstagram. تختار واحدًا، وتعدّل النص إن أردت، فيسلّمك الشرائح وملف PDF للكاروسيل ونص المنشور.

طلب واحد لعلامة دفاتر خيالية. كتب الوكلاء السيناريو، والصوت صوت عصبي مجاني، وأنتجه Remotion، واجتاز خطوة مراقبة الجودة. دون أي تعديل بشري.

وسلّم التشغيل نفسه نسخة بمقاس 4:5 لصفحات LinkedIn وInstagram.

القيود التي وضعتها

  • لا واجهات برمجية مدفوعة. لكل خطوة ذكاء اصطناعي خيار مجاني عبر الإنترنت وبديل محلي: أصوات Piper، وStable Diffusion محليًا، وشخصية كرتونية مدمجة بدل المتحدث المصوَّر.
  • يعمل على حاسوب محمول عادي. على حاسوبي، تُنتَج معاينة مدتها 26 ثانية في نحو 50 ثانية. أما الصورة المولّدة محليًا فتستغرق نحو 9 دقائق على المعالج، ولذلك تأتي الخيارات عبر الإنترنت أولًا.
  • لا شيء يُسلَّم دون فحص. فحص المخطط وخطوة مراقبة الجودة قادران على إيقاف التشغيل.

تطبيق الويب

واجهة خلفية على FastAPI تشغّل Claude Code دون واجهة رسومية، وواجهة أمامية بـ React وTypeScript تعرض كل وكيل وأداة مباشرة أثناء العمل. ويعمل التطبيق في Docker، مع اختبارات وتكامل مستمر عبر GitHub Actions.

الأمان

التطبيق يشغّل وكيل ذكاء اصطناعي على خادم، ولذلك فهو مغلق افتراضيًا:

  • لا يستطيع الوكيل استخدام إلا قائمة أدوات مسموح بها: سكربتات المشروع نفسه، وffmpeg، وبضعة أوامر للقراءة فقط. وكل التكاملات الأخرى محظورة.
  • يجب أن يكون كل ملف مرفوع داخل مجلد الرفع. وتجرّب الاختبارات /etc/passwd و../../etc/passwd و.env.
  • الوضع العام يعمل خلف HTTPS وتسجيل دخول لكل شخص بكلمات مرور مُجزّأة، إضافة إلى ترويسات أمان وحدّ لحجم الملفات المرفوعة.
  • الحاوية تعمل بمستخدمها الخاص لا بصلاحيات الجذر. والمفاتيح في ملف .env خارج git.
