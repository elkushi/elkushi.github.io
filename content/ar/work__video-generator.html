الفكرة

أردت فيديوهات قصيرة تلتزم بهوية العلامة، ولا تكلّف شيئًا للفيديو الواحد، وتُنتَج حتى عندما تتعطل خدمة ذكاء اصطناعي عبر الإنترنت أو تنفد حصتها.

كيف يعمل

يتخذ Claude القرارات، وتنفّذ سكربتات Python العمل.

  1. يحدّد وكيل الاستراتيجية الجمهور وزاوية الطرح وعنصر الجذب (hook) والدعوة إلى اتخاذ إجراء (CTA).
  2. يكتب وكيل السيناريو لوحة القصة (storyboard): التعليق الصوتي، والنص على الشاشة، وأنواع المشاهد.
  3. تُفحَص لوحة القصة وفق مخطط JSON Schema قبل تشغيل أي خطوة بطيئة.
  4. تولّد أدوات Python الصوت، وتجلب الصور والمقاطع أو تولّدها، وتختار الموسيقى.
  5. يُنتج Remotion، وهو إطار عمل للفيديو مبني على React، الفيديو بكل نسب الأبعاد.
  6. تفحص خطوة ضمان الجودة (QA) المدة ومستويات الصوت والإطارات السوداء، وتحوّل التعليق الصوتي إلى نص عبر Whisper لمقارنته بالسيناريو.
  7. يقرأ وكيل المراجعة تقرير ضمان الجودة، ثم يُصدر إما قرار الاعتماد (SHIP) أو قائمة إصلاحات. وبعد جولتَي إصلاح على الأكثر يتوقف التشغيل.

ويُنتج المسار نفسه المنشورات المصوّرة ومنشورات الكاروسيل. وتخرج الفيديوهات بالإنجليزية أو العربية أو الروسية، وتُعرض النصوص العربية على الشاشة من اليمين إلى اليسار.

ثلاثة خيارات، وأنت تختار

في المنشور المصوّر يقدّم التطبيق ثلاث زوايا طرح مختلفة، لكل منها تصميمها ونصّها الخاص لـ LinkedIn وInstagram. تختار واحدة، وتعدّل النص إن أردت، فيسلّمك الشرائح وملف PDF للكاروسيل ونص المنشور.

فيديو جاهز من إنتاج التطبيق

طلب واحد لعلامة دفاتر خيالية. كتب الوكلاء السيناريو، والتعليق بصوت مجاني مولَّد بالشبكات العصبية، وأنتجه Remotion، واجتاز فحص ضمان الجودة. دون أي تعديل بشري.

وأنتج التشغيل نفسه أيضًا نسخة بنسبة 4:5 لموجز المنشورات في LinkedIn وInstagram.

القيود التي وضعتها

  • لا واجهات API مدفوعة. لكل خطوة ذكاء اصطناعي خيار مجاني عبر الإنترنت وبديل محلي: أصوات Piper، وStable Diffusion محليًا، وشخصية كرتونية مدمجة بدل مقدّم يظهر أمام الكاميرا.
  • يعمل على حاسوب محمول عادي. على حاسوبي تُنتَج معاينة مدتها 26 ثانية في نحو 50 ثانية. أما توليد صورة بالذكاء الاصطناعي محليًا فيستغرق نحو 9 دقائق على المعالج (CPU)، ولذلك تأتي الخيارات عبر الإنترنت أولًا.
  • لا شيء يُسلَّم دون فحص. فحص مخطط البيانات وخطوة ضمان الجودة قادران على إيقاف التشغيل.

تطبيق الويب

واجهة خلفية على FastAPI تشغّل Claude Code في الوضع غير التفاعلي (headless)، وواجهة أمامية بـ React وTypeScript تعرض عمل كل وكيل وأداة مباشرةً أثناء التنفيذ. ويعمل التطبيق في Docker، مع اختبارات وتكامل مستمر عبر GitHub Actions.

الأمان

يشغّل التطبيق وكيل ذكاء اصطناعي على خادم، ولذلك فهو مغلق افتراضيًا:

  • لا يستطيع الوكيل استخدام إلا قائمة أدوات مسموح بها: سكربتات المشروع نفسه، وffmpeg، وبضعة أوامر للقراءة فقط. وكل التكاملات الأخرى محظورة.
  • يجب أن يقع كل ملف مرفوع داخل مجلد الملفات المرفوعة. وتجرّب الاختبارات /etc/passwd و../../etc/passwd و.env.
  • يعمل الوضع العام خلف HTTPS، مع حساب دخول مستقل لكل شخص وكلمات مرور مُجزّأة (hashed)، إضافة إلى ترويسات أمان وحدّ لحجم الملفات المرفوعة.
  • تعمل الحاوية بمستخدمها الخاص لا بصلاحيات الجذر (root). والمفاتيح محفوظة في ملف .env خارج git.
