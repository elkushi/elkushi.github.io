Кейс · ИИ-продукт

ИИ-студия, которая пишет, озвучивает и рендерит брендовое видео по нулевой цене за ролик

Моё собственное приложение, сделал его один. На входе один бриф, на выходе готовый пост на английском, арабском или русском — и сразу три варианта на выбор. Превью длиной 26 секунд рендерится примерно за 50 секунд на моём ноутбуке, и ни один шаг не стоит ни цента: у каждого платного API есть бесплатная или локальная замена.

  • Роль: единственный разработчик
  • Стек: Claude Code, Python, FastAPI, React + TypeScript, Remotion, Docker
  • Доказательство: одно реально выданное видео, 24 секунды, 9:16, плюс версия 4:5, без правок человеком
  • Код: github.com/elkushi/ai-video-image-generator
Что это доказывает: я могу собрать ИИ-систему, которая делает работу маркетингового отдела от начала до конца и сама проверяет результат до того, как его увидит человек.

Идея

Мне были нужны короткие видео, которые держат бренд, не стоят ничего за ролик и всё равно выходят, когда онлайновый ИИ-сервис лежит или закончилась квота.

Как это работает

Claude принимает решения. Скрипты на Python делают работу.

  1. Агент-стратег выбирает аудиторию, угол, хук и призыв к действию.
  2. Агент-сценарист пишет раскадровку: закадровый текст, надписи на экране и типы сцен.
  3. Раскадровка проверяется по JSON Schema до того, как запустится хоть что-то медленное.
  4. Инструменты на Python делают голос, находят или генерируют визуал и подбирают музыку.
  5. Remotion, видеофреймворк на React, рендерит все пропорции кадра.
  6. Шаг QA проверяет длительность, уровни звука и чёрные кадры и расшифровывает голос через Whisper, чтобы сверить его со сценарием.
  7. Агент-ревьюер читает отчёт QA и возвращает SHIP или список правок. Не больше двух кругов правок, после этого запуск останавливается.

Тот же конвейер делает посты с картинками и карусели. Видео выходят на английском, арабском или русском. Арабские субтитры идут справа налево.

Три варианта, вы выбираете один

Для поста с картинкой приложение делает три разных подхода, у каждого свой дизайн и свой текст для LinkedIn и Instagram. Вы выбираете один, при желании правите текст — и получаете слайды, карусель в PDF и текст поста.

Готовое видео, сделанное приложением

Один бриф для вымышленного бренда блокнотов. Сценарий написали агенты, голос — бесплатный нейросетевой, рендер сделал Remotion, шаг QA его пропустил. Без правок человеком.

Тот же запуск выдал и версию 4:5 для лент LinkedIn и Instagram.

Ограничения, которые я себе поставил

  • Никаких платных API. У каждого шага с ИИ есть бесплатный онлайн-вариант и локальный запасной: голоса Piper, локальный Stable Diffusion, встроенный маскот вместо говорящей головы.
  • Работает на обычном ноутбуке. На моём превью длиной 26 секунд рендерится примерно за 50 секунд. Локальная ИИ-картинка на процессоре занимает около 9 минут, поэтому онлайн-варианты идут первыми.
  • Ничего не выходит без проверки. Проверка по схеме и шаг QA могут остановить запуск.

Веб-приложение

Бэкенд на FastAPI запускает Claude Code в headless-режиме, а фронтенд на React + TypeScript транслирует работу каждого агента и инструмента в реальном времени. Всё работает в Docker, с тестами и CI на GitHub Actions.

Безопасность

Приложение запускает ИИ-агента на сервере, поэтому по умолчанию закрыто:

  • Агент может пользоваться только разрешённым списком инструментов: собственные скрипты проекта, ffmpeg и несколько команд на чтение. Остальные интеграции заблокированы.
  • Любой загруженный файл обязан лежать внутри папки загрузок. Тесты пробуют /etc/passwd, ../../etc/passwd и .env.
  • Публичный режим работает за HTTPS и персональным входом с хешированными паролями, плюс заголовки безопасности и лимит на размер загрузки.
  • Контейнер работает под собственным пользователем, не под root. Ключи лежат в .env, вне git.
