Кейс · ИИ-продукт

ИИ-студия, которая пишет, озвучивает и рендерит брендированное видео без затрат на каждый ролик

Мой собственный проект, сделанный в одиночку. На входе один бриф, на выходе готовый пост на английском, арабском или русском, причём три варианта на выбор. 26-секундное превью рендерится на моём ноутбуке примерно за 50 секунд, и ни один шаг ничего не стоит: у каждого платного API есть бесплатная или локальная замена.

  • Роль: единственный разработчик
  • Стек: Claude Code, Python, FastAPI, React + TypeScript, Remotion, Docker
  • Подтверждение: одно реальное готовое видео — 24 секунды, 9:16, плюс версия 4:5, без ручных правок
  • Код: github.com/elkushi/ai-video-image-generator
Что это доказывает: я могу построить ИИ-систему, которая от начала до конца выполняет работу маркетинговой команды и проверяет собственный результат ещё до того, как его увидит человек.
0 €на платные API: у каждого ИИ-шага есть бесплатный онлайн-вариант и локальная замена
~50 сна рендер 26-секундного превью на обычном ноутбуке
3 вариантана каждый бриф, у каждого свой дизайн и свой текст
3 языкаанглийский, арабский и русский; арабские титры идут справа налево

Идея

Мне нужны были короткие видео в стиле бренда, которые ничего не стоят в производстве и которые можно сделать, даже когда онлайн-сервис ИИ недоступен или исчерпан лимит.

Как это работает

Решения принимает Claude. Работу выполняют скрипты на Python.

  1. Агент-стратег выбирает аудиторию, угол подачи, хук и призыв к действию.
  2. Агент-сценарист пишет раскадровку: закадровый текст, текст на экране и типы сцен.
  3. Раскадровка проверяется по JSON Schema до запуска любых долгих шагов.
  4. Инструменты на Python создают озвучку, находят или генерируют визуал и подбирают музыку.
  5. Remotion, видеофреймворк на React, рендерит ролик во всех форматах кадра.
  6. QA проверяет длительность, уровень звука и чёрные кадры, а также расшифровывает озвучку через Whisper и сверяет её со сценарием.
  7. Агент-ревьюер читает отчёт QA и возвращает SHIP или список правок. Максимум два круга правок, после этого запуск останавливается.

Тот же пайплайн делает посты с изображениями и карусели. Видео выходят на английском, арабском или русском; арабские титры идут справа налево.

Три варианта на выбор

Для поста с изображением приложение предлагает три разных угла подачи, у каждого свой дизайн и свой текст для LinkedIn и Instagram. Вы выбираете один, при желании правите текст, и приложение выдаёт слайды, PDF-карусель и текст поста.

Готовое видео, сделанное приложением

Один бриф для вымышленного бренда блокнотов. Сценарий написали агенты, озвучка — бесплатный нейроголос, рендер — Remotion, и ролик прошёл проверку QA. Без ручных правок.

Тот же запуск выдал и версию 4:5 для лент LinkedIn и Instagram.

Ограничения, которые я себе поставил

  • Никаких платных API. У каждого ИИ-шага есть бесплатный онлайн-вариант и локальная замена: голоса Piper, локальный Stable Diffusion, встроенный маскот вместо говорящей головы.
  • Работает на обычном ноутбуке. На моём 26-секундное превью рендерится примерно за 50 секунд. Локальная генерация одного изображения занимает около 9 минут на процессоре, поэтому сначала пробуются онлайн-варианты.
  • Ничего не уходит без проверки. Проверка схемы и этап QA могут остановить запуск.

Веб-приложение

Бэкенд на FastAPI запускает Claude Code в headless-режиме, а фронтенд на React и TypeScript в реальном времени показывает работу каждого агента и инструмента. Всё работает в Docker, с тестами и CI на GitHub Actions.

Безопасность

Приложение запускает ИИ-агента на сервере, поэтому по умолчанию всё закрыто:

  • Агент может пользоваться только разрешённым списком инструментов: скриптами самого проекта, ffmpeg и несколькими командами только для чтения. Все прочие интеграции заблокированы.
  • Каждый загруженный файл должен находиться в папке загрузок. Тесты пробуют /etc/passwd, ../../etc/passwd и .env.
  • Публичная версия работает только по HTTPS, с персональным входом для каждого пользователя и хешированными паролями, плюс заголовки безопасности и лимит на размер загрузки.
  • Контейнер запускается от отдельного пользователя, а не от root. Ключи лежат в .env, вне git.
