02 · How I build

Security basics

An AI app that can run commands needs limits. These are in the code, not just in a policy.

  • AI agents get an allowlist of tools, never open shell access.
  • Uploads and file paths are checked, so nobody can read files outside the app. Tests try /etc/passwd and ../ and expect a refusal.
  • Servers run HTTPS, key-only SSH and logins with hashed passwords.
  • Keys stay in .env, and every repo is scanned for secrets before it goes public.
  • Containers run as a normal user, not root.
